Motivation

A part request starts with a photo

When a ship's generator needs a replacement part, an engineer often sends the supplier a photo of the worn part: no label, no part number, poor engine-room lighting. Someone experienced has to recognize it by eye before anything can be quoted or sourced. That step is slow, depends on a few experts, and a wrong identification means a wrong order and a second delay.

Engineer sends photoIdentify the partLook up sourcesSend quote

PartSight automates the highlighted step: given a photo, it predicts which of six high-volume parts it shows.

Fuel injector

Most frequently replaced wear part on generator engines.

Turbocharger

High-value unit; fast identification speeds up large quotes.

Piston

Overhaul item with many crown shapes and sizes.

Connecting rod

Long forged part, easily confused with others.

Crankshaft

Large, expensive, with long lead times.

Oil filter

High-volume consumable ordered constantly.

Technical approach

AlexNet with transfer learning

AlexNet (Krizhevsky, Sutskever & Hinton, 2012) won the ImageNet challenge with a 15.3% top-5 error rate versus 26.2% for the runner-up, and launched the deep-learning era in computer vision. It has five convolutional layers that learn visual features (edges, then textures, then shapes) and three fully connected layers that turn those features into class scores.

Transfer learning

Start from ImageNet-pretrained weights, replace the final 1000-class layer with a 6-class layer, and fine-tune the whole network.

Preprocessing

Resize to 224×224, normalize with ImageNet mean/std. Training images get random crops, flips, ±15° rotations and color jitter.

Training

Cross-entropy loss, Adam optimizer, learning rate 1e-4, batch size 32, 12 epochs. Best epoch chosen on validation accuracy.

Tracking

Every run is logged to Weights & Biases: loss and accuracy per epoch plus a test-set confusion matrix.

Dataset

Building the dataset

Sixty web image searches (ten per part) returned 1,695 photos. Corrupt, tiny and near-duplicate files were removed, then CLIP, a second pretrained model that matches images to text, threw out every photo that did not clearly show the part it was searched for: people, maps, logos, labeled diagrams and multi-part shots. That left 1,101 clean photos, split 70% train, 15% validation and 15% test with a fixed seed. The test set is used only once, for the final score.

Experiments

Change one thing at a time

Each experiment changes a single setting from the baseline, so any difference in accuracy can be attributed to that setting. All runs use cross-entropy with label smoothing 0.1, Adam, a cosine learning-rate schedule and 15 epochs.

Results

What the experiments showed

Results appear here automatically once figures/results_summary.csv from the Colab notebook is added to this repository.

Best model: ResNet50, 98.8% test accuracy. Best AlexNet: 90.1% (batch size 16).

Learning rate mattered most. At 1e-3 the large updates wiped out the pretrained ImageNet weights, and accuracy collapsed to 20.9%, no better than always guessing the most common part. At 1e-5 the model learned too slowly and reached only 84.3%. 1e-4 was best.

Batch size had a small effect. Batch 16 (90.1%) edged out 32 (89.0%) and 64 (87.2%). Smaller batches make more weight updates per epoch, and their noisier gradients act as mild regularization. The spread is about 5 test photos, so it is a weak effect.

Augmentation slowed memorization. Without it, training accuracy hit 100% by epoch 4 while validation accuracy stalled. The test gain was small (89.0% vs 88.4%) because label smoothing and pretrained weights already limit overfitting.

Architecture made the biggest jump. ResNet18 (95.3%) and ResNet50 (98.8%) beat AlexNet with the same ~4 minutes of training, thanks to deeper networks with skip connections and stronger pretrained features.

Data quality mattered more than any hyperparameter. With the first, uncleaned web images the model was unsure even on clear photos (30% confidence on an obvious turbocharger). CLIP filtering and more searches lifted ResNet50 from 89.6% to 98.8%. One caveat: the test photos are clean web photos, so accuracy on real engine-room photos will be lower until the model is trained on them.

Takeaways

What I learned and what's next

  • Transfer learning makes small datasets workable. A network pretrained on 1.2 million ImageNet photos already understands metal textures and shapes; it only needs a few hundred images per part to adapt.
  • Data quality beats tuning. Automatically filtering wrong web images with CLIP did more than any hyperparameter.
  • Controlled experiments matter. Changing one setting at a time is the only way to know what actually helped.
  • Know when to say "not sure." Below 60% confidence PartSight asks for a human instead of guessing, which matters more than the last percent of accuracy in a quoting tool.
  • Next steps: train on real warehouse and engine-room photos, add classes (cylinder heads, fuel pumps, gaskets), predict exact part numbers, and ship it as a phone app for engineers.
